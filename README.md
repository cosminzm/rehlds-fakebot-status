# 🎮 ReHLDS FakeBot Status

### Show YaPB bots with Steam2-style IDs in `status`

A custom Linux i386 build of **ReHLDS 3.14.0.857** that modifies the `status` output so YaPB fake clients are displayed with Steam2-style IDs instead of `BOT`.

---

## ✨ Features

- ✅ YaPB bots are no longer displayed as `BOT`
- ✅ Each bot receives a different Steam2-style ID
- ✅ IDs are randomly generated
- ✅ IDs remain stable while the bot is connected
- ✅ Works with ReHLDS `3.14.0.857`
- ✅ Linux i386 `engine_i486.so`
- ✅ YaPB and Reunion remain unchanged
- ✅ Build is fully automated with GitHub Actions
